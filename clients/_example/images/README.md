# images/

Coloca aqui os ficheiros do cliente:

- `logo.svg` (ou `.png`) — referenciado em `config.ts` no campo `logo`.
- `gallery/*.jpg` — fotos para a secção Galeria (uso futuro; atualmente a
  Galeria mostra ícones temáticos por defeito até haver fotos reais).

Estes ficheiros são servidos automaticamente em
`/site/<nome-do-cliente>/images/<ficheiro>` — não precisas de os copiar para
`public/`.
